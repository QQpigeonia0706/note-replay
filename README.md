# Note Replay

> 记录你打字修改笔记的全过程，像视频一样回放你是怎么写出这篇笔记的。

**Note Replay** 是一个 Obsidian 插件，它会在后台默默记录你编辑笔记的历史快照，让你能够随时打开回放面板，像看视频一样拖动进度条、倍速播放，回顾一篇笔记的诞生过程。

## ✨ 核心功能

- ⏱️ **自动快照**：编辑笔记时，自动最多每 600ms 记录一次文字版本快照，无需手动操作。
- 🎬 **全屏回放面板**：按下快捷键 `Ctrl + Alt + G`（或 `Cmd + Option + G`），打开当前笔记的回放面板。
- ⏪ **自由拖动与倍速**：可以拖动进度条回看任意一步的修改，支持 `0.5x` 到 `16x` 超高倍速播放（高倍速下采用固定步进，真正“嗖嗖嗖”）。
- 📦 **导出与删除**：在回放面板右上角，支持一键将当前笔记的所有历史导出为 JSON 文件，或单独清空当前笔记的快照。
- 🛡️ **例外分区**：在设置中可以指定某些文件夹（如“私人日记”、“临时剪贴板”）完全不记录任何快照，保护隐私。
- 🧹 **智能存储优化**：
  - **自动过期**：所有快照仅保留 7 天，启动时和每小时自动清理过期数据。
  - **等间隔抽稀**：单篇笔记最多保留 1000 条记录。超出时，会在完整时间区间内**等间距**删除旧快照（首尾保留），不会导致早期记录全部丢失。

## 🚀 安装方法

### 方法一：Obsidian 社区市场（审核通过后可用）
1. 打开 Obsidian 设置 -> 第三方插件 -> 社区插件市场。
2. 搜索 `Note Replay` 并安装启用。

### 方法二：手动安装（当前可用）
1. 在本仓库的 [Releases](链接到你的Releases页面) 页面下载最新的 `main.js`、`manifest.json` 和 `styles.css`。
2. 在你的 Vault 文件夹中，找到 `.obsidian/plugins/` 目录（如果没有则手动创建）。
3. 新建一个名为 `note-replay` 的文件夹，将下载的三个文件放入其中。
4. 打开 Obsidian，在“第三方插件”中关闭安全模式，刷新并开启 `Note Replay`。

## 📖 使用说明

| 操作 | 说明 |
| --- | --- |
| 正常写笔记 | 插件会在后台自动记录，无需干预 |
| `Ctrl + Alt + G` | 打开/关闭当前笔记的回放面板 |
| `空格键` | 播放 / 暂停回放 |
| `←` / `→` | 单步后退 / 前进 |
| `⏮` / `⏭` 按钮 | 跳回起点 / 跳到最新状态 |
| 进度条 | 任意拖动到某个历史时刻 |
| 右上角 `⬇ 导出` | 导出当前笔记的编辑历史为 JSON |
| 右上角 `🗑 删除全部` | 清空当前笔记的所有快照（不影响笔记内容） |

## ⚙️ 设置与数据

在 **设置 -> Note Replay** 中可以查看当前占用的存储空间、各笔记的快照数量，并进行手动清理。

**例外分区**：
在设置里输入文件夹名称（每行一个），该文件夹下的所有笔记将不再记录任何快照。如果之前已经记录了，可以点击“立即清理”一键抹除。
